# EqyCord

[Download the latest release](https://github.com/zztwi/EqyCord-releases/releases/latest).

This repository contains official downloads and update manifests. Development is maintained separately in a private repository. Each distributed version includes its corresponding GPL-3.0-or-later source in EqyCord-source.zip; recipients may study, modify and redistribute covered code under that license. Vencord, Equicord and imported plugin notices are preserved inside the source and installer.

## Downloads

- EqyCord-Setup.exe: Windows x64 installer for Stable, PTB and Canary.
- EqyCord-Web.zip: portable browser package; replace and reopen it manually when updating.
- SHA-256 files: checksums for those downloads.
- EqyCord-source.zip: matching source, license and custom-plugin instructions. Personal plugins use src/userplugins and a source build.

Native update assets and eqycord-update.json are used by the official client updater. Builds from before the public-channel migration need the new installer once. No GitHub token or payment method is needed by recipients to download public releases.

Publication is performed locally after validation while hosted Actions is unavailable. No future release is published without running the release process.
